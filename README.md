## Что это за проект?

Данный проект был создан в рамках третьей контрольной работы по предмету - создание программного обеспечения

## Что возможно в этом проекте

- Вы можете зарегистрироваться в качестве арендатора или арендодателя
- Можете создавать помещения для аренды в качестве арендодателя
- Бронировать помещения на определенный срок в качетсве арендатора
- добавлять помещения в избранное, удалять из избранного
- получать уведомления о своих арендах
- искать по каталогу, применять фильтры
- отменять бронирования
- удалять места в качестве арендодателя

и многое другое `:)`

попробуйте сами.
